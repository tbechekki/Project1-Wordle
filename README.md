
# Project 1 - *Wordle*

Submitted by: **Taha Echekki**

**Wordle** is an app that is a guessing game, that the user has to guess a 5 letter word that refreshes every game. they have a limited number of quesses and it lets you know if a letter is in the word, not in the word, or in the right position in the word.
